Duración propuesta: 18 horas · Ruta web · Material Design 3 como referencia visual

Resultado de aprendizaje

Genera interfaces gráficos de usuario mediante editores visuales utilizando las funcionalidades del editor y adaptando el código generado.

Producto del RA

El alumnado obtiene con un editor visual y herramientas de IA un gestor sencillo de tareas. Aprende a reconocer componentes, propiedades, métodos, datos, eventos y escuchadores; modifica fragmentos delimitados del código generado y comprueba el resultado. No programa una interfaz desde cero.

Flujo de cada clase

  1. Mostrar un resultado visible y formular una pregunta concreta.
  2. Generar o abrir la salida preparada de Stitch, Gemini o AI Studio.
  3. Localizar componentes y fragmentos relevantes sin explicar todo el código.
  4. Pedir una modificación acotada y revisar las diferencias.
  5. Ejecutar casos normales, límites y errores.
  6. Relacionar la evidencia con el criterio evaluado.

Herramientas

  • Stitch: propuesta y reorganización visual de pantallas.
  • Gemini / Google AI Studio: generación, explicación y cambios delimitados.
  • Editor visual web: creación, colocación y edición de componentes.
  • Navegador y DevTools: inspección, eventos y comprobación del resultado.
  • HTML, CSS y JavaScript: salida de IA que se identifica y explica, no temario de programación desde cero.
  • Material Design 3: referencia para componentes, jerarquía y estados.

Evaluación

Las trece prácticas aportan evidencias breves sobre los conceptos del currículo y el integrador cubre los ocho criterios. La calificación debe valorar el uso real del editor, la comprensión del código generado, la modificación controlada y el funcionamiento comprobado; una captura aislada no basta.

Preparación del profesor

  • Verificar los accesos al editor visual y las herramientas de IA.
  • Preparar los fragmentos y proyectos iniciales indicados en cada unidad.
  • Mantener una versión inicial y otra resuelta del gestor.
  • Facilitar alternativas si una generación falla, sin dar por demostrado el criterio.
  • Reservar Android Studio, XML y Java para ampliación voluntaria.
