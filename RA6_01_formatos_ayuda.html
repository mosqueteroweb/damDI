Objetivo docente

Distinguir ayuda integrada, HTML, PDF, guía rápida y referencia, eligiendo el formato por tarea, actualización y contexto.

Contenido para explicar

HTML permite navegación, búsqueda y actualización; PDF favorece impresión y versión cerrada; Markdown mantiene una fuente editable; la ayuda contextual responde dentro de la tarea. No basta exportar el mismo texto: cada formato conserva propósito, versión, accesibilidad y enlaces válidos.

RA6-EJ01 · Ejemplo resuelto

Una guía «Crear tarea» usa HTML para consulta diaria y PDF para entrega sin conexión. Ambas incluyen versión, requisitos, cuatro pasos, resultado y solución de dos errores. El HTML añade enlace contextual desde el formulario.

# Crear una tarea
**Versión comprobada:** 1.6
1. Abre **Nueva tarea**.
2. Escribe un título.
3. Selecciona módulo y fecha.
4. Pulsa **Guardar tarea**.
**Resultado:** aparece en la lista y se anuncia la confirmación.

RA6-PB01 · Dos formatos coherentes

Genera con IA una ayuda corta, verifícala en la aplicación y produce HTML y PDF desde el mismo Markdown. Compara navegación, impresión, actualización y accesibilidad.

Solución orientativa

Mostrar ejemplo de solución

El Markdown contiene versión, pasos probados y recuperación. El HTML mantiene encabezados y enlaces; el PDF conserva orden y fecha. La comparación concluye que HTML es principal y PDF complementario. Se corrige un nombre de botón inventado por la IA antes de generar.
