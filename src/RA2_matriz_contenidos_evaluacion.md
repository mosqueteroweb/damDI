# RA2 · Matriz de contenidos, prácticas y criterios

## Criterios de evaluación completos

| CE | Evidencia exigida |
|---|---|
| RA2.a | Se han identificado las herramientas disponibles para el aprendizaje automático relacionadas con las interfaces de usuario. |
| RA2.b | Se ha creado una interfaz natural de usuario utilizando las herramientas disponibles. |
| RA2.c | Se ha utilizado el reconocimiento de voz para implementar acciones en las interfaces naturales de usuario. |
| RA2.d | Se ha incorporado la detección del movimiento del cuerpo para implementar acciones en las interfaces naturales de usuario. |
| RA2.e | Se han integrado elementos de detección de partes del cuerpo para implementar acciones en las interfaces naturales de usuario. |
| RA2.f | Se ha integrado la realidad aumentada en los interfaces de usuario. |

## Regla de suficiencia

Cada criterio requiere funcionamiento o simulación reproducible, decisión justificada y explicación individual del fragmento generado. Una captura, una predicción sin prueba o un sensor sin alternativa no bastan. No se califican rasgos físicos ni la capacidad de hablar o moverse de una persona.
