# RA6-INT01 · Centro de ayuda del gestor

## Situación

El gestor va a distribuirse y necesita documentación verificable para usuarios, soporte y administración. Los borradores automáticos contienen nombres y pasos que no siempre coinciden con la versión real.

## Encargo

Con Stitch, Gemini/AI Studio y el generador estático, crea y publica un sistema de ayuda completo. Parte de plantillas y borradores de IA; ejecuta cada procedimiento, corrige y conserva evidencias.

## Requisitos obligatorios

1. Identificar y justificar el sistema de generación.
2. Generar ayuda habitual en HTML y una salida PDF o imprimible.
3. Añadir ayuda contextual en crear, filtrar y borrar.
4. Documentar esquema y versión de la información persistente.
5. Crear manual de usuario y guía de referencia.
6. Crear instalación, configuración y administración.
7. Elaborar un tutorial probado por otra persona.
8. Incluir contenidos, índice, búsqueda, FAQ, versión y fecha.

## Entregables

- Fuentes Markdown y salidas generadas.
- Arquitectura visual de Stitch.
- Manuales por destinatario y diccionario de datos.
- Tutorial, registro de prueba y corrección.
- Prompts y tabla afirmación–comprobación–resultado.
- Informe de enlaces, teclado, búsqueda y responsive.
- Defensa individual de cinco minutos.

## Casos de prueba mínimos

| Caso | Resultado esperado |
|---|---|
| Buscar «alta» | Encuentra Crear tarea |
| Ayuda desde borrar | Abre tema exacto y permite volver |
| HTML/PDF | Mismo procedimiento y versión |
| Datos | Campos coinciden con una muestra real |
| Instalación limpia | Termina con verificación observable |
| Restauración | Incluye copia previa y criterio de éxito |
| Tutorial externo | Otra persona completa el objetivo |

## Guía de corrección por criterios

| CE | Satisfactorio | Insuficiente |
|---|---|---|
| a | Compara y justifica sistema de ayuda | Solo nombra herramienta |
| b | Genera formatos habituales accesibles | Copias manuales incoherentes |
| c | Tres ayudas abren contenido pertinente | Enlace a portada genérica |
| d | Esquema, reglas, versión y recuperación | Lista de campos incompleta |
| e | Manual de usuario y referencia diferenciados | Un único texto sin audiencia |
| f | Instalación, configuración y administración verificadas | Pasos no ejecutados |
| g | Tutorial probado y mejorado | Borrador sin prueba externa |

## Solución docente orientativa

<details><summary>Mostrar estructura de una solución válida</summary>

El centro de ayuda se genera desde Markdown, ofrece contenidos, búsqueda e índice, y enlaza desde tres contextos. El manual de usuario se orienta a tareas; la referencia documenta controles y datos; los manuales técnicos incluyen precondiciones, verificación y recuperación. El diccionario coincide con el almacenamiento versionado. Un tutorial de informe se prueba con otra persona y registra una corrección. El informe automático de enlaces y una revisión manual de teclado confirman la publicación.

</details>

## Preguntas de defensa

1. ¿Qué afirmación del borrador de IA tuviste que comprobar o corregir?
2. ¿Cómo garantizas que HTML y PDF describen la misma versión?
3. ¿Qué diferencia existe entre manual de usuario y guía de referencia?
4. ¿Qué evidencia demuestra que la ayuda contextual conduce al tema exacto?
5. ¿Qué cambió después de que otra persona probara el tutorial?
